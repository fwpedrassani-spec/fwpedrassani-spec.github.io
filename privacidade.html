Política de Privacidade do app Canal

Última atualização: 6 de novembro de 2026.

O Canal é uma ferramenta particular, usada só pelo dono do canal do YouTube O Que o Terreno Diz para produzir e publicar os vídeos desse canal. Ele não é oferecido ao público e não tem outros usuários.

O que o app acessa

Com a autorização do dono do canal, pela conta Google dele, o Canal usa os YouTube API Services para:

  • enviar vídeos, miniaturas, legendas e textos ao próprio canal, e agendar a publicação;
  • ler as estatísticas do próprio canal (YouTube Analytics), incluindo as de receita, para avaliar os episódios.

Ele não acessa dados de outros canais nem de espectadores, além dos números agregados que o YouTube Analytics fornece ao dono do canal.

Onde os dados ficam

O token de acesso fica guardado no Gerenciador de Credenciais do Windows, no computador do dono do canal. As estatísticas lidas ficam num banco de dados local, no mesmo computador. Nada é vendido, compartilhado com terceiros nem usado para publicidade.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Quando isso acontece, os dados guardados no computador deixam de ser atualizados e podem ser apagados pelo dono.

Termos do YouTube e do Google

Ao usar este app, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de uso limitado.
